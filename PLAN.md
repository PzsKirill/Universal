## 2. Что объединяет победителей (выводы)

1. **Палитра из 2 цветов.** Почти у всех: тёмный + один акцентный (лайм, оранжевый, зелёный).
2. **GSAP есть практически везде**, у большинства ещё Three.js/WebGL. Плавный скролл (Lenis), прелоадер, переходы между страницами — базовый минимум.
3. **Одна фирменная фишка на сайт** (спираль, мир-игра, hold-to-proceed, морфинг), а не десяток эффектов.
4. **Сторителлинг:** сайт ведёт посетителя по истории, а не вываливает блоки.
5. **Слабое место победителей — доступность и семантика** (оценки 6.6–7.6 из 10). **Наш шанс выделиться:** Lighthouse 95+, `prefers-reduced-motion`, корректная семантика.
6. **Эффекты бывают двух типов.**
   - **Чистый код:** шейдеры, типографика, GSAP-анимации. Claude пишет их целиком, это наша сильная сторона, начинаем с них.
   - **Нужны ассеты:** иллюстрации, 3D-модели, видео. Их нужно отдельно произвести: сгенерировать AI и векторизовать, нарисовать самим или заказать.

## 3. Концепция портфолио

**Хаб «[Имя] × Claude»** — лаборатория, где каждая работа — концепт-сайт в своём жанре.
**Уникальное отличие:** у каждой работы есть страница «Как это сделано с Claude»: ключевые промпты, число итераций, часы, было → стало, метрики Lighthouse. На Awwwards процесс почти никто не показывает, а для нашей цели это главное доказательство.

**Вариант концепции хаба:** ретро-мультфильм в духе ntch.design со своими персонажами: «человек + робот-Claude» делают сайты в мастерской. Переходы между страницами — «ирис» из старых мультиков, проекты оформлены как «эпизоды», поверх зерно плёнки. Требует иллюстраций.

Проект 6 нужен потому, что Awwwards-эксперименты впечатляют, а клиенты платят за рабочие продающие сайты.

## 5. Технический стек (предложение)

- **Хаб:** Astro + MDX (кейсы как контент) + View Transitions + GSAP + Lenis
- **Демо-проекты:** Vite + TypeScript + GSAP + Lenis + Three.js (по необходимости Matter.js, Rive, Howler для звука)
- **Репозиторий:** монорепо на pnpm workspaces (`apps/hub`, `apps/01-editorial`, …), общий пакет дизайн-токенов
- **Деплой:** Vercel (каждый проект на своём поддомене или пути), GitHub
- **Ассеты:** правила и реестр лицензий в [ASSETS.md](ASSETS.md)
  - 3D: Poly Haven, Kenney, Quaternius, Poly Pizza, Smithsonian 3D (CC0); Sketchfab и Free3D — только после проверки лицензии конкретной модели
  - Свои ассеты: SVG-иллюстрации, процедурное 3D, шейдеры и Blender-скрипты, всё пишет Claude
  - Шрифты: Google Fonts, Fontshare. Фото и видео: Unsplash, Pexels. Звуки: Freesound (только CC0)
  - Рабочие AI-коннекторы компании в этом проекте не используем

### Хостинг и показ работодателю
- **Хостинг бесплатный:** Vercel, Hobby-план. Деплой автоматический при каждом push в GitHub, сайты доступны по адресам вида `name.vercel.app`.
- **Репозиторий публичный на GitHub:** работодатель видит код и историю коммитов.
- **Домен покупаем позже, на этапе запуска:** около $10–15 в год за .com/.dev. Подключается к Vercel бесплатно, HTTPS тоже бесплатный.
- **В резюме:** ссылка на хаб, ссылка на GitHub и видео 30–60 сек.
- **В каждом репозитории:** README с GIF или скриншотом, live-ссылкой, стеком и описанием, как сделано с Claude.
